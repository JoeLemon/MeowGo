# MeowGo

把原来「手动编辑 `cmd.xls` + 命令行按 enter」的流程，改成**在界面上直接配置步骤并执行**。
识别点击、热键、输入、系统命令等能力与旧版完全一致，并且仍然兼容旧版 `cmd.xls`。

新版把步骤装进**可复用的执行组**：左侧维护组，右侧编辑组里的步骤，组与组之间可以互相调用。
界面上没有「项目」概念——**所有执行组自动保存**（`rpa_settings.json`），下次打开还在。

在旧版能力之外，还加了这些**降低门槛**的东西：条件步骤、窗口操作、坐标点击/拾取、
变量传递、拖拽、宏录制（真实鼠标操作录成步骤）、数据驱动（一份流程跑多批数据）、
定时运行、Windows 计划任务（无人值守）、运行报告与失败截图、结果回写与断点续跑、
撤销重做、图片管家、配置备份，以及不开界面的命令行模式。

界面体验上还有这些**好用的小东西**：运行进度条与迷你置顶条、步骤搜索、斑马纹与
类型徽章、图片预览窗格与对话框预览按钮、深色主题、步骤批量多选、拖拽落点指示线、单步调试、
更精致的猫爪开关控件，以及**简体中文 / English 界面切换**。

## 快速开始

```bat
:: 1. 安装依赖（只需一次）
pip install -r requirements.txt

:: 2. 启动（推荐双击 启动GUI.bat，不会出现黑色控制台）
python start-app.py
```

如果你已经在用旧版并且装好了 `pyautogui / xlrd / pillow / opencv-python`，可以跳过第 1 步。

## 界面说明

```
菜单栏   品牌 Logo | 文件 / 编辑 / 运行 / 视图 / 帮助（自绘，与右键菜单同款下拉）
工具栏   ⚙ 设置 | … ▶运行组  循环  暂停  停止（导入/导出 Excel 在菜单栏「文件」里）
左 栏    执行组（文件夹式，可展开看组里的步骤；按住可拖拽调整顺序，有暖橙落点线指示插入位置）
右 栏    当前组的步骤列表（双击单元格即可修改；行可拖拽排序；支持多选批量操作；顶部有搜索框）
下 方    运行日志（可收起）+ 进度条 + 状态栏
```

顶部品牌 Logo 用重新抠图的 `meowgo_logo_transparent.png`（透明背景；深色主题自动反白，保留橙色圆点）；窗口 / 任务栏图标仍用 `main.png`，`main.svg` 保留为矢量源文件。

主面板、运行日志、图片预览和搜索框统一为圆角卡片；配色、间距、圆角、字号与按钮层级按 `MeowGo_界面视觉规范.md` 的 Design Tokens 落地：暖白 / 墨黑 / 暖橙三色为主，语义色只用于成功、警告、失败和信息提示。步骤表使用中性灰白表头 + 白色行 + 浅灰选中行，包在圆角细描边容器内；滚动条改为浅色圆角轨道 + 深色滑块 + 白色猫爪；语言、执行组和类型选择统一为带猫爪按钮的圆角下拉，不再使用原生 `ttk.Combobox` / `ttk.Scrollbar`。文本输入统一由 `uikit.TextField` 绘制：外层只保留一圈圆角描边，内部 Entry 无边框，搜索框、步骤表单、运行设置与定时 Webhook 不再出现双边框；运行设置采用标签左对齐、控件右对齐的两端对齐布局，步骤表首列图标槽加宽、编号列收窄，列宽可拖动调整并随配置保存，下次启动恢复上次效果；日志头「运行日志 / 复制 / 清空」按钮在浅色主题下悬停时保持深色底。所有按钮仍由 `uikit.RoundButton` 绘制，按强调 / 次 / 描边 / 幽灵 / 危险五档统一配色与边框。空状态使用像素猫插画（191×160 网格 / 130 色，源自 `images/像素猫-canvas绘制.html`，由 `rpa/pixel_cat.py` 内联解码；桃色内耳、暖橙项圈，中性色随主题在 paper↔ink 间重映射，暖色移入品牌暖橙），带轻微呼吸浮动和定时眨眼；Windows 11 下窗口本身也使用原生圆角，并跟随主题切换深色标题栏。橙色猫爪开关保持原设计，不随按钮改版。

组和步骤的增删改移**都放在右键菜单里**（自绘的圆角菜单，与界面同风格，
带图标、快捷键提示；当前不可用的项会自动变灰）：

- 在**左栏的组**上右键：运行这个组 / 循环运行 / 新建 / 重命名 / 复制为副本 / 上移 / 下移 / 删除；
- 在**右栏的步骤**上右键：新增 / 编辑 / 复制 / 截取屏幕替换图片 / 上移 / 下移 / 删除；
- 顶部菜单栏（文件 / 编辑 / 运行 / 视图 / 帮助）提供同样的功能，展开后按钮会高亮；
- 菜单弹出后，**在别处（哪怕是别的程序窗口）点一下左键就会收起**；
- 在菜单外**点右键**时会收起当前菜单，并就地弹出指针下面那块的菜单
  （比如正开着「文件」下拉时，在步骤列表上右键会直接换成步骤菜单）。
- 组和步骤都支持**拖拽排序**：按住某一行拖到目标行松开即可（把组拖到另一个组
  展开后的某条步骤上，就会归入那个组——用来整理大流程很好用）。

### 界面体验改进

**运行进度**：

- 日志区上方有**进度条**：带数据运行时显示「第 x/y 行」，循环/调用次数已知时显示步数；
  循环次数未知（`-1`）时是**脉冲动画**，告诉用户「还在跑，没卡死」；
- 可选**迷你置顶进度条**（设置里勾「运行时显示迷你进度条」）：一条小小的置顶条，
  窗口最小化时也能看到整体进度，跑完自动消失；
- 步骤列表会**高亮当前执行行**，跑完的成功/失败行分别染成绿/红色。

**步骤搜索**：步骤列表顶部的搜索框，按「步骤名或内容」实时过滤，
右上角显示 `命中数/总数`；`Esc` 清空。步骤多的时候不用滚屏找。

**斑马纹与类型徽章**：步骤列表隔行浅色条纹，配合类型列的小色块，
长列表看起来不累、找行更快（颜色随深浅主题自动切换）。

**图片预览窗格**：选中图片类步骤（单击/双击/右键/条件）时，列表下方直接显示
缩略图、文件名和尺寸，点「在文件夹中显示」跳到原图——不用打开图片目录翻。

**对话框图片预览**：新增/编辑步骤的对话框里，「截图」「选图」旁边就是「预览」按钮，
点开按窗口大小**整图查看**当前内容框里的图片（附原始尺寸、文件大小、在文件夹中显示），
截图或选图后可以立刻核对截得对不对，不用先保存再跑一次看效果。

**深色主题**：菜单「视图 → 切换到深色主题」或 `Ctrl+D`，整站（菜单、列表、
对话框、按钮、图标）一起换肤，选择会被记住，下次打开还是深的。

**界面语言**：菜单「视图 → 运行设置…」中的「界面语言」可选择**简体中文**或
**English**，保存后立即生效，并写入 `rpa_settings.json` 记住选择。菜单、按钮、
提示、状态栏、日志、设置、步骤与定时任务对话框会同步切换；执行组名、步骤内容、
文件路径、Webhook 地址等**用户数据保持原样**，不会被翻译。

**开关控件**：开关采用浅灰 / 品牌暖橙轨道、带柔和投影的白色猫爪滑块与缓动动画，
开启态保持品牌暖橙；悬停、键盘焦点与禁用状态均有清晰区分。定时任务列表每行都有
独立开关，可直接启停。

**文案风格**：面向客户端用户的说明、提示与空状态统一使用完整、正式的表述，
避免口语化措辞；日志与错误信息保留可定位问题的关键细节。

**批量操作**：步骤列表支持 `Ctrl` / `Shift` **多选**（或 `Ctrl+A` 全选），
右键菜单可对选中的一批步骤**批量复制 / 删除 / 上移 / 下移**（整块移动，保持相对顺序）。

**拖拽落点指示线**：拖拽排序时跟手显示一条暖橙细线，标出松手后会插到哪一行；
拖到最后一行下方会排到列表末尾，不用瞄像素。

**单步调试**：菜单「运行 → 单步调试开关」或 `F8` 打开调试模式（或右键组 →
「单步调试运行这个组」跑一次）。开启后每一步执行前都会弹出确认框：
**运行**继续、**跳过**跳过这步、**停止**中止整场——配合运行报告能快速定位是哪一步出问题。

**启动预热**：首次运行如果还没加载过识别引擎，第一步可能要等一二十秒
（底层是 OpenCV 首次导入）。程序会在启动时**后台预热**，第一步不再干等。

### 执行组与复用

- 界面以**执行组**为单位：运行、暂停、停止都作用在当前选中的组上。
- 想复用别的组：在某个组里新增一条 **调用执行组** 指令，内容填目标组名即可；
  重复次数写 `3` 就调用 3 次，写 `-1` 就是一直调用。
- 运行前会自动校验：调用的组是否存在、是否存在**循环调用**（A 调 B、B 又调 A）、
  内容格式是否合法，有问题会弹窗并写进日志。
- 改组名时会自动更新所有指向它的调用指令。
- 首次启动会自动预置 **5 个模板组**：打开浏览器、打开软件、批量打开网址、
  上传文件、打开工作环境。改组里的变量（`浏览器` / `窗口标题` / `网址` /
  `软件` / `文件路径`）即可运行；已有执行组不会被覆盖，删掉后也不会再自动加回。
- 误删了预置组：菜单 **编辑 → 恢复预置执行组…**，或左侧组列表右键 →
  **恢复预置执行组…**，会把缺失的模板补回来；同名组保留，不覆盖。
- **打开浏览器** 会等待浏览器窗口真正出现并激活后再操作地址栏；用 Edge 时
  把 `窗口标题` 变量改成 `Edge`。
- **批量打开网址** 配合数据运行：Excel / CSV 里准备一列 `网址`，带数据运行时
  会逐行打开；没有数据时打开 `网址` 变量里的默认链接。
- **上传文件** 需要先把页面上的上传按钮截图保存为 `images/上传按钮.png`，
  再把 `文件路径` 变量改成要上传的文件。
- 左侧点开某个组可以看到它的步骤（只读概览）；点其中一条会跳到右侧对应行。

### 配置一条步骤

- **新增**：在右侧列表里右键 →「新增步骤…」→ 选类型 → 填内容 → 确定；
- **修改**：在列表里**双击单元格**直接改（类型列是下拉框），或选中行按 `F2` 开对话框；
- **图片类步骤**（单击/双击/右键）：在对话框点 **截图** 框选屏幕按钮，或点 **选图** 选已有 png；
  也可以选中列表里的图片步骤，右键 →「截取屏幕并替换图片…」直接替换；
- **排序 / 复制 / 删除**：同样在步骤的右键菜单里（快捷键 `Delete` 删除、`Ctrl+Enter` 新增）。

### 高级选项：识别范围、第几个、灰度、等待与重试

步骤对话框默认只显示「类型 / 内容 / 重复次数」，点底部的 **高级选项** 才展开
（默认收起，不增加日常配置负担）。里面的设置都有安全默认值，**不填就是旧行为**：

- **等待**：`0` = 一直等（默认，与旧版一致）；图片 / 拖拽 / 条件步骤可以填
  「最多等几秒」。条件步骤超时后按「没出现」处理，继续走对应分支；
- **超时后**（图片 / 拖拽）：`跳过这步`（默认，记一次失败后继续）或
  `停止执行`（立即中止整场）。「跳过」的步骤在日志和报告里都会标成失败；
- **识别范围**：只在这块区域里找图，格式 `x,y,宽,高`；点 **框选** 直接在屏幕上拖，
  留空 = 全屏。缩小范围能明显减少误点，也能让「第几个」更稳定；
- **第几个**：同一张图出现多次时，`1` = 最左上（默认），`2` = 第二个……
- **灰度**：忽略颜色差异，只比形状和明暗；适合按钮颜色会变、切换主题的场景；
- **失败重试**：失败后自动再试几次，以及每次间隔几秒；只重试非致命失败，
  致命错误（如组不存在）不会白重试；
- **输入方式**（输入文本）：`粘贴`（默认，快，支持中文）或 `逐字输入`
  （个别不认剪贴板的应用；中文会自动回退到粘贴）；
- **检测图片**（图片类）：隐藏窗口后真的在当前屏幕找一次，直接告诉你
  「命中 1 处 / 命中 3 处 / 没找到」，不用先跑一遍流程试错。

图片内容还支持几个简短写法（旧的四列 Excel 仍然只写文件名即可）：

| 写法 | 含义 |
|---|---|
| `a.png;b.png` | 依次尝试多个候选，前一个没找到就试下一个 |
| `a.png@100,200,300,400` | 只在这个区域里找（x,y,宽,高） |
| `a.png#2` | 取第二个命中（同「高级选项 → 第几个」） |
| `a.png+10,-5` | 在命中点基础上偏移（先右 10、再上 5） |

后缀可以组合，顺序是 `图片@范围#第几个+偏移`，如
`按钮.png@0,0,800,600#2+10,-5`。

### 坐标步骤：不用截图，直接点位置

- **坐标点击**（`click_xy`）：内容写 `x,y`，如 `500,300`；加第三段 `,right` 表示右键；
  重复次数照常生效（填 `2` 就是连点两下）；
- **移动鼠标**（`move_xy`）：只把鼠标移到 `x,y`，不点击；
- 对话框里点 **拾取** 按钮：有 3 秒倒计时，期间把鼠标挪到目标位置再点一下左键，
  坐标自动填好（按 `Esc` 取消）。

### 条件步骤：屏幕上出现图片才执行

- **条件：出现图片则执行**（`if_image`）：内容写 `图片名|组名`，如 `弹窗.png|关闭弹窗`；
  运行时先找图片，**找到了就调用指定组**，找不到就跳过（不报错）；
- 对话框里填好图片名后，点 **选组** 按钮会弹出全部组名的菜单，选一个即可，
  不用手打组名（打错了运行时会提示找不到执行组）；
- 条件也支持「高级选项 → 等待」：填几秒就最多等几秒，到点还没出现就按
  「没出现」处理（例如 `if_not_image` 会继续执行）。

### 窗口操作

- **窗口操作**（`window`）：三种写法——
  - `activate:标题`：把标题包含这段文字的窗口激活并带到前台（最小化会自动还原）；
  - `wait:标题|秒`：等窗口出现（默认 5 秒，可自己填），出现了就激活；
  - `close:标题`：给窗口发关闭消息。
- 适合「先激活目标软件再操作」「等某个窗口弹出来」这类场景；
  等待超时会报错并中止整场执行（报告里能看到是哪一步）。

### 宏录制：把真实鼠标操作录成步骤

菜单「编辑 → 宏录制鼠标操作…」（或工具栏）：

1. 点开始后**正常操作鼠标**——单击、双击、右键、滚轮、拖拽都会被记下来；
2. 控制条自己区域内的点击不会录进去（免得录到「停止」按钮本身）；
3. 点 **停止** 生成步骤（自动接在当前组步骤列表末尾），或 **取消** 放弃；
4. 录出来的内容：`click_xy`（含双击合并、右键）、`move_xy`（位移超过 60px 才记，
   免得满屏都是移动）、`scroll`（滚轮按格记，100 = 1 格）。

录制走的是 Windows 底层鼠标钩子，**录的是真实操作**，与识图点击可以混着用。

> 说明：合成注入的鼠标移动不过底层钩子，所以宏录制只响应真实硬件操作——
> 这正是它该有的样子。

### 热键步骤：直接按按键录入（推荐）

配「热键组合」时不用再对着输入法敲 `ctrl,s`——点内容框右侧的 **⌨ 按键录入** 按钮
（或双击热键步骤的内容列，点那个小键盘按钮），然后**直接按下组合键**：

- 按下 `Ctrl+Shift+A` → 全部松开，自动写入 `ctrl,shift,a`（修饰键自动排在前）；
- 录的是**原始按键**，中文输入法开着也不怕——逗号不会被输入法变成全角「，」，
  字母也不会掉进输入法候选里；录制期间按键被临时接管，不会漏进别的控件；
- **小键盘数字**会自动写成 `num0~num9`（引擎只认这种写法）；
- 单独按 `Esc` 取消录入，恢复原来的内容；录完还能继续手动改；
- 在列表里双击热键步骤的内容列，同样有这个按钮。

> 旧版限制：引擎不识别**顶层数字键**（`1`~`0` 那排），需要数字时请按小键盘数字键，
> 误按了会有提示。热键最多 10 个按键。

### 管理执行组

- 在左侧组上右键：新建 / 重命名 / 复制为副本 / 上移 / 下移 / 删除（快捷键 `Ctrl+G` 新建组）。
- 展开组可以看到它包含的步骤；点其中任意一条会跳到右侧对应行。

### 数据驱动：一份流程跑多批数据

同一条流程，对着一张表逐行跑，内容里的 `{占位符}` 会替换成当前行的值：

- **准备数据**：CSV 或 Excel（第一行是表头，如 `名字,密码`），行数不限；
- **写占位符**：步骤内容里写 `{列名}`（对应表头列）、`{index}`（当前行号，从 1 开始）、
  `{date}`（今天日期）、`{time}`（当前时刻）、`{random}`（4 位随机数）、
  `{变量名}`（「设置变量 / 复制到变量」存下的值，见下文「变量」一节）；
  列和变量都不存在时**保留原样**，方便发现拼写错误；
- **跑法**：
  - 界面：菜单「运行 → 带数据运行…」选文件；
  - 命令行：`python start-app.py --run 组名 --data 数据.csv`；
- 日志里会有「—— 第 2/5 行 ——」的分隔，运行报告里每步都带**行号**。

跑完还会自动在数据文件旁边写一份 **`<数据文件名>.result.csv`**（UTF-8 BOM，
Excel 直接打开不乱码）：保留原数据列，追加 `__行号 / __结果 / __失败步骤`，
以及流程里用「设置变量 / 复制到变量」存下的列。默认开启，可在设置里关掉。

**断点续跑**：下次选同一份数据时，会问「上次跑到第 N 行，是否继续？」——
选「是」跳过已经跑过的行，选「否」从头跑。如果最后一行失败了（例如致命错误
中止），会从失败的那一行继续重试，而不是直接跳过。命令行对应 `--from-row N`
（跳过前 N 行；失败的行走完也会记在结果文件里，方便事后单独重跑）。

例：数据表有 `名字` 列，流程里写一步「输入文本 → 你好{名字}」，
5 行数据就会依次输入「你好甲 / 你好乙 / …」。

### 编辑辅助：撤销重做 / 配置备份 / 图片管家

- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（菜单「编辑」里也有）。新增、改名、删除、
  移动、内联修改、导入 Excel、宏录制、恢复备份**全部可以撤销**（最多 50 步）；
- **配置备份**：每次保存前会自动把上一版配置复制到 `backups/`（留最近 10 份）。
  菜单「文件 → 从备份恢复…」可以挑一份恢复，双击即可；
- **图片管家**（菜单「视图 → 图片管家…」）：一张表列出所有 png 及**被哪些步骤引用
  （引用几次）**。支持：
  - **重命名**：所有引用它的步骤会自动跟着改，不会断；
  - **清理未引用**：列出没人用的图，确认后删除（释放 `images/` 空间）；
  - 顺带显示文件大小，找大图很方便。

### 执行

- **运行组**：执行当前选中的组（`F5` 全局热键，任何窗口下都有效；或在组上
  右键 →「运行这个组」）；**循环**：反复执行直到停止；菜单「运行 → 运行全部组」按左侧顺序跑所有组。
- 点运行后会先弹出倒计时，倒计时结束窗口自动最小化（避免遮挡识别区域）。
- 「设置」里可以关掉「失败时保存截图」和「数据跑完写结果文件」，默认都开启。
- 运行中会高亮当前正在执行的那一行，日志里能看到「▶ 进入执行组「X」」的嵌套过程。
- 停止方式：
  - 按 **F9**（全局热键，任何窗口下都有效）；
  - 或把鼠标快速甩到**屏幕左上角**（pyautogui 的 failsafe，会立即中断并报错）；
  - 或用「暂停」临时挂起。

### 定时运行与完成通知

菜单「运行 → 定时运行…」：

- 左侧是**定时任务列表**：可新增、选中修改、删除，每行有独立开关可快速启停；
- 右侧编辑当前任务：填写**时:分**（24 小时制）、选择要执行的组，保存后到点自动执行；
- 支持同时存在多条任务（不同时间 / 不同执行组），互不影响；
- 顶栏**时钟图标**（「运行设置」左边）点开是浮窗：列出即将执行的定时任务和
  实时倒计时，浮窗里的「历史」可查看近期定时执行情况（触发时间 / 任务 / 结果 /
  耗时，保留最近 60 条记录），「管理」直接打开定时任务对话框；
- 可选**提示音**（任务结束后播放提示音）和 **Webhook**（任务结束后向所填地址
  发送 JSON，便于接入企业微信 / 钉钉 / 飞书的机器人）；
- 同一天同一条任务的同一个时刻只会触发一次，第二天到点继续；若执行组已被删除，
  仅在日志中提醒，并在历史中记录一条「已跳过」，不会弹出打扰提示；
- 到点时如果客户端正忙（例如正在执行其他任务），会跳过这一次，不会出现两个流程
  同时争用鼠标的情况。

**无人值守（Windows 计划任务）**：同一个对话框底部可以「创建计划任务」/
「删除计划任务」，使用 Windows 自带的任务计划程序，到点启动无界面运行，
**即使关闭 MeowGo 也能按时执行**，而且不需要管理员权限：

- 用当前任务的时间和执行组创建，任务名形如 `MeowGo_组名`；重复创建会覆盖同名任务；
- 计划任务以无头模式运行，同样会写运行报告、失败截图和结果文件；
- 「删除计划任务」只删除系统任务，不影响软件内的定时设置；
- 软件内定时（界面开着才有效）和 Windows 计划任务二选一即可，无需同时启用。

**不会出现两个流程争用鼠标**：同时打开两个界面会被拦截；界面正在运行、或计划任务
正在执行时，另一个运行会提示「已有运行在进行」并跳过，不会相互干扰。

### 开机自启

菜单「视图 → 运行设置…」里勾**开机自动启动**并保存：会在**当前用户**的注册表
`Run` 项里写入启动命令（不需要管理员权限），下次登录 Windows 自动打开 MeowGo。

- 只开界面，**不会自动跑流程**——到点无人值守跑流程请用「定时运行 → 创建计划任务」；
- 取消勾选并保存即移除启动项；开关状态直接反映注册表实况，两边不会不一致；
- 程序被整体搬家（换目录 / 重装）后，重新保存一次设置就会更新启动命令；
- 登录时如果界面已经开着，新实例提示「MeowGo 已经在运行」后退出，不会抢配置。

### 系统托盘

「运行设置…」里有两个托盘开关（任一打开，右下角通知区就会出现 MeowGo 图标）：

- **启动后最小化到托盘**：配合开机自启，登录后直接安静进后台，不弹窗口；
- **关闭窗口时最小化到托盘**：点右上角 × 只是收起窗口，程序继续在后台运行。

托盘行为：

- **双击图标**（或左键单击）重新打开窗口；**右键菜单**有「显示主窗口 / 退出」，
  「退出」是真正退出——运行中的任务会先确认，配置照常保存；
- 关窗收起和启动隐藏时各弹一次气泡说明，不搞突然消失；
- 窗口藏在托盘时如果正在跑任务，跑完会弹气泡告知结论（成功 / 失败 / 步数 /
  耗时），点气泡打开窗口——不会强行把窗口弹到前台；
- 图标跟随主题：浅色主题是墨黑猫，深色主题自动反白（与窗口标题栏 Logo 同源）；
- **关机 / 注销不受影响**：系统会话结束时 MeowGo 会直接退出，不会「关窗躲托盘」
  挡系统关机；
- 两个开关都取消并保存，托盘图标随即消失；窗口正藏着时会被先放出来再退。

> 托盘只负责「界面在不在前台」，跑流程仍靠「定时运行 → 创建计划任务」
> （关掉 MeowGo 也能跑）；两者互不依赖。

### 运行报告与日志导出

- 每跑完一次（无论成功失败），都会在程序目录 `reports/` 下写一份
  `run_日期_时间.md`：结果、步数、失败数、总耗时、数据行数，以及**每一步**的
  组名 / 行号 / 类型 / 内容 / 耗时 / 成败；
- **失败截图**：失败的步骤会自动截一张当前屏幕，存到 `reports/shots/`，
  报告里多一列「截图」，点「查看」直接打开。截图可能含敏感信息，可在设置里
  关掉「失败时保存截图」；
- **报告索引**：菜单「文件 → 打开报告索引」打开 `reports/index.html`，
  最近 100 次运行一张表（时间 / 结果 / 步数 / 失败 / 耗时），点「查看报告」
  打开详情；超出 100 份的旧报告、以及 7 天前且没人引用的旧截图会自动清理；
- 菜单「文件 → 打开运行报告目录」直接打开这个文件夹；
- 菜单「文件 → 导出日志…」把当前日志窗的内容存成文本文件，出问题甩给别人看。

## 指令类型对照（与旧版 Excel 编号一致）

| Excel 第1列 | 类型 | 内容写法 |
|---|---|---|
| 1 | 左键单击 | 图片文件名，如 `按钮.png` |
| 2 | 左键双击 | 图片文件名 |
| 3 | 右键单击 | 图片文件名 |
| 4 | 输入文本 | 要输入的文字（走剪贴板粘贴） |
| 5 | 等待 | 秒数，如 `1.5` |
| 6 | 滚轮 | 距离，正数向上、负数向下，如 `-200`（100 = 1 格） |
| 7 | 热键组合 | 英文逗号分隔，如 `ctrl,s` 或 `win,r`；也可用「按键录入」直接按 |
| 8 | 粘贴当前时间 | 固定填 `当前时间` |
| 9 | 系统命令 | CMD 命令，如 `start notepad` |
| 10 | 调用执行组 | 要调用的组名（新版扩展，实现步骤复用） |
| 11 | 条件：出现图片则执行 | `图片名\|组名`，如 `弹窗.png\|关闭弹窗` |
| 12 | 窗口操作 | `activate:标题` / `wait:标题\|秒` / `close:标题` |
| 13 | 坐标点击 | `x,y`，如 `500,300`；加 `,right` 表示右键 |
| 14 | 移动鼠标 | `x,y`，如 `500,300`（只移动，不点击） |
| 15 | 条件：没出现图片则执行 | `图片名\|组名`，如 `错误.png\|重试` |
| 16 | 条件：二选一 | `图片名\|出现执行\|没出现执行` |
| 17 | 条件：窗口存在则执行 | `窗口标题\|组名`，如 `记事本\|处理` |
| 18 | 设置变量 | `变量名=值`，如 `订单号={index}` |
| 19 | 复制选中文字到变量 | `变量名`，如 `订单号` |
| 20 | 拖拽 | `起点\|终点`，各自是图片名或 `x,y`，如 `文件.png\|回收站.png` |

热键注意事项（沿用旧版限制）：最多 10 个按键；单个数字键不识别（用 `num0` 这类写法）；
英文逗号是分隔符，不能作为按键本身。

> 新版类型（11~20）只在界面上用编号兼容 Excel 导入导出；`超时/超时后 /
> 识别范围 / 第几个 / 灰度 / 重试 / 输入方式` 这些高级参数只存在 JSON 里，
> Excel 仍保持四列，旧表可以继续直接导入（高级参数走默认值）。

### 条件、变量与拖拽（类型 15~20）

- **条件：没出现图片则执行**（`if_not_image`）：`if_image` 的反面——屏幕上
  **没有**这张图时才调用指定组。适合「错误弹窗没出现才算成功」这类判断；
- **条件：二选一**（`if_else`）：`图片名|出现时执行的组|没出现时执行的组`，
  对话框里有两个「选组」按钮分别填；「没出现」的组留空表示什么都不做；
- **条件：窗口存在则执行**（`if_window`）：按标题子串找窗口，存在才调用组
  （只判断，不激活；要激活用「窗口操作」）；
- **拖拽**（`drag`）：`起点|终点`，两端各自写图片名或 `x,y`——混搭也行
  （如 `文件.png|800,600`）。截图 / 选图 / 拾取会填进第一个空着的一段；
  两端都就位后才按下鼠标，等不到会按「超时后」策略处理，不会把界面卡在
  拖拽状态里。

### 变量：把上一步的结果交给下一步

「设置变量 / 复制选中文字到变量」让流程有了**记忆**：

- **设置变量**（`set`）：`变量名=值`，值里可以用占位符，如 `行号={index}`、
  `名字={数据表里的列名}`；
- **算术表达式**：`set` 的值若是**纯算式**（`+ - * / // % **` 和括号，如
  `计数={计数}+1`、`总价={单价}*{数量}`）会自动算出结果再存；含文字或符号
  则按字符串原样保存（如 `编号=订单-{序号}` 不会被误算）；
- **复制选中文字到变量**（`copy`）：先手动选中文字，这一步替你按一次 `Ctrl+C`，
  把剪贴板内容存进变量（你原来的剪贴板内容之后会还原，不会被破坏）；
- **读回**：之后任意步骤的内容里写 `{变量名}` 即可，如「输入文本」写 `订单号是{订单号}`；
- **作用范围**：一场运行内有效——`run()` 开始时清空，之后同一次运行里的
  所有组、所有数据行、所有循环轮次共享；带数据跑时每行都会覆盖上一行的值；
- **优先级**：`{名字}` 这样的占位符，先查数据列、再查变量，都找不到才保留原样
  （方便发现拼写错误）；`{index}` / `{date}` / `{time}` / `{random}` 始终是内置含义。

例：数据表有 `订单号` 列，流程写「设置变量 当前单号={订单号}」→「单击 查询.png」→
「输入文本 {当前单号}」→「复制选中文字到变量 结果」，就能把每行的查询结果
存进变量，最后一步「输入文本 结果：{结果}」汇总输出。

## 与 Excel 互转

一个工作表 = 一个执行组，表头固定为 `指令类型 / 内容 / 重复次数(-1无限) / 备注`。

- **导入单个组**：菜单「文件 → 导入 Excel（单个组）」→ 导入为单个执行组（只取第一个工作表，按文件名命名）；
- **导入全部**：菜单「文件 → 导入 Excel（全部工作表）」→ 导入全部工作表（每个工作表一个组，组名 = 工作表名）；
- **导出当前组**：菜单「文件 → 导出当前组为 Excel」→ 导出当前组（单个工作表）；
- **导出所有组**：菜单「文件 → 导出所有组为 Excel」→ 导出所有组（多工作表，工作表名 = 组名）；
- 支持 `.xls`（旧版 `cmd.xls` 也能直接导入）与 `.xlsx`，工作表名里的非法字符会自动清理；
- **状态文件**：程序目录下的 `rpa_settings.json` 会实时保存所有执行组 + 图片目录 + 运行设置，
  不需要手动保存；旧版只有单一列表的 json 也能读入（会变成「默认组」）。

首次运行时的「图片目录」默认为程序目录下的 `images/`，可在「设置」里改，或菜单「文件 → 打开图片目录」直接打开。

## 图片素材怎么截才好

识别用的是模板匹配，**截取的区域要在整屏内唯一**：

- 只截按钮中间的一段（不要把旁边相似按钮一起框进去）；
- 不要截到会变化的内容（数字、光标、进度条、动画）；
- 同一张图在屏幕上出现多次时，默认命中**最左上的一个**；要明确点第几个，
  在步骤「高级选项 → 第几个」里填，或内容写 `图片.png#2`；
- 只在某个区域里找：用「高级选项 → 识别范围」，或内容写
  `图片.png@x,y,宽,高`；范围比全屏更稳，也更不容易点错；
- 按钮颜色会变（主题、选中态）时，勾上「灰度」；
- 识别不出来时，把「设置 → 图片相似度」从 `0.9` 调到 `0.85` 再试。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示缺少依赖 | 照弹窗里的命令 `pip install ...` 安装，或双击 `启动GUI.bat` 自动装 |
| 图片识别不到 | 重新截图、缩小区域、降低相似度；先点「高级选项 → 检测图片」看当前屏幕能不能命中 |
| 提示 `The confidence keyword argument is only available if OpenCV is installed` | 没装 OpenCV，命令行执行 `pip install opencv-python`，装好后重启 MeowGo |
| 点击位置偏移 | 程序已声明 DPI 感知，请勿在多显示器缩放不同的情况下跨屏识别；可用「识别范围」限定区域 |
| 提示「循环调用」 | 组之间互相调用成了环，去掉其中一条调用即可 |
| 停不下来 | 按 F9，或鼠标甩到屏幕左上角 |
| 滚轮滚不动 | 内容按「100 = 1 格」写（如 `200` = 2 格），程序会换算成系统认识的增量 |
| 定时没跑 | 软件内定时只在界面开着时有效；要关界面也跑，用「定时运行 → 创建计划任务」 |
| 点 × 程序没退 | 「运行设置」里勾了「关闭窗口时最小化到托盘」；托盘右键 → 退出才是真退出 |
| 关机被 MeowGo 挡住 | 不会——系统会话结束时自动退出；若勾了托盘选项也同理 |
| 提示「已有运行在进行」 | 另一个界面或计划任务正在跑，等它结束；不要同时开两个流程抢鼠标 |
| 计划任务创建失败 | 看对话框里的 schtasks 提示；任务名重复会自动覆盖，权限不足时可在「任务计划程序」里手动创建 |
| 结果文件在哪 | 数据文件旁边，名字是 `<数据文件名>.result.csv`；设置里可以关掉结果回写 |
| Win7 报错 | 安装 `WIN7补丁/windows6.1-kb2533623` |

## 无头运行（不开界面）

界面里配好的组，可以直接在命令行跑——适合接计划任务 / CI / 远程服务器：

```bat
:: 看看有哪些组
python start-app.py --list

:: 跑指定的组
python start-app.py --run 主流程

:: 按左侧顺序跑所有组
python start-app.py --all

:: 循环跑（Ctrl+C 停）
python start-app.py --run 主流程 --loop

:: 带数据跑：CSV/Excel 第一行是表头，每行跑一遍
python start-app.py --run 群发流程 --data 通讯录.csv

:: 断点续跑：跳过前 10 行，从第 11 行继续
python start-app.py --run 群发流程 --data 通讯录.csv --from-row 10

:: 报告写到指定目录（默认 reports\）
python start-app.py --run 主流程 --report D:\logs
```

跑完会在报告目录里生成 `run_日期_时间.md` 并刷新 `index.html`（内容与界面
运行报告一致），控制台里也能看到每一步的日志。运行前会先校验步骤格式和图片
文件是否存在。数据驱动还会在数据文件旁边写 `<数据文件名>.result.csv`，
下次可以接着跑；失败截图按设置写到报告目录的 `shots/`。

无头模式同样有单实例锁：同一时间只允许一个自动运行，已有运行时会打印
「另一个 MeowGo 正在运行，本次跳过」并以 0 退出，不会两个流程抢鼠标。

## 打包成 exe

一键打包脚本（Windows PowerShell / macOS / Linux 通用，自动建虚拟环境、装依赖、转平台图标）：

```bat
:: Windows（PowerShell / CMD 均可）
python build.py

:: macOS / Linux
python3 build.py
```

也可以用各平台原生入口脚本（自动寻找 Python 3.9+，参数原样透传，效果同上）：

```powershell
# Windows PowerShell（项目根目录）
.\build.ps1                        # 等价于 python build.py
.\build.ps1 --onefile --verify     # 单文件 + 打包后自检

:: 首次运行如提示"禁止运行脚本"，先执行：
:: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
:: 或临时绕过：powershell -ExecutionPolicy Bypass -File .\build.ps1
```

```bash
# macOS / Linux
./build.sh                         # 首次如无执行权限：bash build.sh
./build.sh --onefile --launcher    # 单文件 + 生成双击启动脚本
```

常用选项：`--onefile` 单文件、`--clean` 清场重打、`--no-venv` 用当前环境、
`--skip-deps` 跳过装依赖、`--verify` 打包后冒烟自检、`--launcher` 生成双击启动脚本
（macOS `.command` / Linux `.sh`）、`--name 名称` 改产物名、`--mirror 地址` 换 pip 镜像。

产物：Windows 默认得到 `dist\MeowGo\MeowGo.exe`（单文件夹，约 170MB，含 OpenCV）；
加 `--onefile` 则只得到 `dist\MeowGo.exe`（单文件，无 `_internal`，首次启动会先解压到临时目录，稍慢）。
macOS 额外得到 `dist\MeowGo.app`（Finder 双击；`MEOWGO_NO_APP=1` 可关闭）；
Linux 默认得到 `dist\MeowGo\MeowGo`，单文件模式为 `dist\MeowGo`。执行组与截图会写到 exe 同目录下的
`rpa_settings.json` 和 `images\`。

也可以完全手动（旧方式）：

```bat
pip install -r requirements.txt pyinstaller
python -m PyInstaller --noconfirm "MeowGo.spec"
:: 结果：dist\MeowGo\MeowGo.exe（单文件夹，约 170MB，含 OpenCV）
:: 执行组与截图会写到 exe 同目录下的 rpa_settings.json 和 images\
```

打包后可以自动验证产物能正常起窗口：

```bat
python tests\verify_exe.py     :: 启动 exe、按进程 ID 找到窗口、截图 tests/exe_preview.png 后关闭
```

## 命令行单独用引擎

```python
from rpa.engine import Executor, Group, Step

ex = Executor()
ex.log = lambda level, msg: print(f"[{level}] {msg}")
ex.groups = {
    "登录": [Step("click", "登录按钮.png"), Step("input", "admin")],
    "主流程": [Step("call", "登录"), Step("wait", "0.5")],
}
ex.run("主流程")          # 只跑主流程（内部会调用登录组）

# 数据驱动：每一行完整跑一遍，{列名} 替换成当前行的值
ex.data = [{"名字": "甲"}, {"名字": "乙"}]
ex.groups["群发"] = [Step("input", "你好{名字}"), Step("wait", "0.2")]
ex.run("群发")

# 图片步骤的失败策略：最多等 3 秒，等不到就跳过这步继续
ex.groups["容错"] = [Step("click", "可能不出现的.png", timeout=3,
                          on_fail="skip")]

# 变量：set/copy 写入，任意内容里用 {变量名} 读回（一场运行内有效）
ex.groups["变量演示"] = [Step("set", "单号={index}"),
                        Step("input", "第{单号}单")]
ex.run("变量演示")

# 条件与拖拽
ex.groups["分支"] = [Step("if_else", "弹窗.png|关弹窗|等弹窗"),
                    Step("drag", "文件.png|回收站.png")]
ex.run("分支")
```

新版能力（窗口操作 / 坐标步骤 / 条件步骤 / 数据驱动 / 运行报告）全部在引擎里，
界面只是接线——可以不开界面直接驱动，也可以接到自己的程序里。
